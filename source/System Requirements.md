## System Requirements

### OS requirements
CellBack is implemented in Python and can be run on both Linux and Windows.

Tested systems:
- Linux (recommended): Ubuntu 18.04 / 20.04 / 22.04, CentOS 7
- Windows: Windows 10 / 11

### Python requirements
Python **>= 3.8**
